# 歌声合成デモ（学習モデル版）

UST（楽譜）を、**実際の歌声から学習したモデル**に歌わせるプロジェクト。

`D:\音声合成デモ_高校生向け\`（ルールベースのフォルマント合成）とは**完全に独立**。
あちらは Web Audio だけで動く完成品として凍結してあり、こちらとファイルを共有しない。
デモ当日は「ルールで作った声」と「データから学んだ声」を**同じ楽譜で聴き比べる**のが狙い。

> **この公開版について**：市販曲・投稿曲（UTAU用UST）を学習モデルに歌わせた音声は
> 著作権上の配慮からこのリポジトリには含めていません。同梱の4曲はすべてパブリックドメイン
> （かえるのうた／きらきら星／ちょうちょ／音階とあいうえお）です。
> 任意のUSTファイルをその場で読み込んで合成する**ライブモード**は機能として残っており、
> 手元で好きな曲を試せます（詳細は後述の「自分のUSTをその場で歌わせる」）。
> また、学習データ本体（PJS corpus, 274MB）もこのリポジトリには含めていません
> （ライセンス上の配布不可・サイズの両方の理由。取得方法は下記「データとライセンス」参照）。

## いま動くところまで

```bash
python engine/prepare.py                     # PJS 100曲 → WORLD特徴量（済：26.9分）
python engine/train.py --epochs 400          # 音響モデル学習（済：val L1 0.618）
python engine/synth.py --copy pjs100         # 実データのラベル+F0から再合成（品質の上限確認）
python engine/synth.py --ust songs/kaeru.ust # UST を歌わせる ★これが本番
python engine/synth.py --ust songs/kaeru.ust --no_vibrato   # ビブラートなし版
```

出力は `output/`。`check/` には分析→再合成（モデルを通さない）の音があり、
**ボコーダの品質上限**がここで聴ける。

## 仕組み

```
UST（音符＋歌詞）
  ↓ parse_ust / lyric_to_phones     かな→音素、tick→秒、NoteNum→Hz
音素列 + F0軌跡（ポルタメント・ビブラート付き）
  ↓ AcousticModel                   ★学習した部分
メルケプストラム60次元 + 非周期性4次元
  ↓ WORLD (pyworld)
wav（24kHz）
```

**F0 は楽譜から決まるのでモデルには入力として渡す。** モデルが学ぶのは
「その音素を、その高さで歌うと、どんな響きになるか」＝音色だけ。
位相もスペクトルの細部も予測しないので、27分という少ないデータでも破綻しない。

| 部品 | 内容 |
|---|---|
| 音響モデル | 音素埋め込み(前・現・次)＋位置・長さ・logF0・有声 → 膨張畳み込み6層（±0.6秒を参照）→ 64次元 |
| パラメータ数 | 約 1.6M |
| ボコーダ | WORLD（pyworld）。位相を扱わない |
| 特徴量 | 24kHz / 5ms フレーム / メルケプストラム60次 + 非周期性4次 |

`engine/dsp.py` はメルケプストラム変換の自前実装（pysptk がこの環境で入らないため）。
周波数軸をメル尺度へ伸縮 → 対数 → DCT。**再構成誤差 2.2 dB RMS**（60次のとき）。

## 確認済みの数値

| 項目 | 値 |
|---|---|
| 学習データ | PJS corpus 100曲 / 26.9分 / 36音素 |
| 検証 L1 損失 | 0.618（正規化後） |
| 分析→再合成の誤差 | 2.2 dB RMS（60次メルケプストラム） |
| UST合成の音程 | 楽譜どおり MIDI 60/62/64/65 を検出、有声率 0.90 |

女性1名・歌100曲＋読み上げ100文・48kHz・音素ラベルとmusicXML付き。

- 実演で鳴らすのは問題ない（表示＝クレジットが条件）

- 配布物には次を明記すること：

```
学習データ：PJS corpus (Junya Koguchi, Shinnosuke Takamichi) / CC BY-SA 4.0
```

**東北きりたん歌唱データベースは使わない。** 配布根拠が著作権法30条の4（非享受利用）で、

## ブラウザデモ（当日用）

`デモを開く.bat` をダブルクリック → `web/index.html` が開く。Python・GPU 不要。

- **① 楽譜を歌わせる**：4曲（かえるのうた／きらきら星／ちょうちょ／音階とあいうえお）を
  「ルールベース」と「学習モデル」で聴きくらべ。**再生中に切り替えると位置を保ったまま声だけ入れ替わる**
- **② 本物と比べる**：PJS の実際の歌声と、同じ楽譜・同じF0で歌わせた学習モデルを並べて再生
- **③ しくみ**：2つの声のつくりかたの違い

各トラックに **波形**（上）と **スペクトログラム**（下）を並べて表示し、
再生位置に白い縦線が両方を同時に走る。読み込んだ UST も同じ表示になる。

波形は事前に 900 点へ間引いたピーク値（`prerender_web.peaks`）を JSON に埋め込み、
ブラウザ側の canvas で描画している。色はトラックごと（青＝ルール／緑＝学習／橙＝本物）。

プレイヤーは **トラックごとに `Audio` を1つずつ持ち、切り替えは再生権の受け渡しだけ**を行う
（1つの `Audio` の `src` を差し替える方式だと、切り替えのたびに読み込み直しが起きて
位置の引き継ぎが失敗する）。ロジックの検証は `node engine/test_player.js` で実行できる
（DOM と Audio を模擬して、位置の引き継ぎ・停止中の切り替え・シークを自動チェック）。

**シークバーは2トラック共通**。トラックを切り替えても再生位置は保たれ、
再生中でも停止中でも同じ位置のまま声だけが入れ替わる。
波形・スペクトログラムを直接クリック／ドラッグしても頭出しできる
（別トラックの絵をクリックすると、そのトラックに切り替わってその位置から鳴る）。

### 作り直す手順

```bash
python engine/make_songs.py                  # デモ用 UST を生成（全曲パブリックドメイン）
python engine/synth.py --ust songs/kaeru.ust # 学習モデルで歌わせる（4曲ぶん繰り返す）
python engine/rule_synth.py --ust songs/kaeru.ust
python engine/synth.py --copy pjs001         # 比較用（pjs100 も）
python engine/prerender_web.py               # web/audio, web/data を書き出し
```

`engine/rule_synth.py` は比較用のルールベース合成。UST パーサ・F0軌跡・ボコーダは学習モデル版と
**完全に共通**で、スペクトル包絡の作り方（表引き vs ニューラルネット）だけが違う。
つまり聴こえる差はすべて「包絡をどう決めたか」の差になる。

### 自分の UST をデモの標準曲にする

`ust/` フォルダに .ust を置いて、次を実行するだけで曲リストに追加される。

```bash
python engine/render_all.py            # songs/ と ust/ の全曲を2方式で合成
python engine/render_all.py --max_sec 45   # 長い曲は先頭45秒だけにする（推奨）
python engine/prerender_web.py         # ブラウザ用の素材を書き出し
```

`render_all.py` は `output/index.json` に一覧を残し、`prerender_web.py` がそれを読む。
日本語ファイル名は `user1` `user2` … というキーに変換されるが、**画面上の曲名はファイル名のまま**。

現在収録：かえるのうた／きらきら星／ちょうちょ／音階とあいうえお（以上パブリックドメイン）のみ。
（作業時は`ust/` に市販曲・投稿曲のUSTを置いて2曲を追加していたが、この公開版では
著作権上の配慮によりそれらのUSTと生成音声を除外している。）

**注意1：容量** フル尺の曲を入れると `web` が 85MB まで膨らむ。
配布用には `--max_sec 45` で作り直すと 20MB 程度に収まり、デモの進行としてもちょうどいい。

**注意2：著作権** 市販曲・投稿曲の UST から合成した音は、その曲の著作物の利用にあたる。
校内などで**無料・無報酬・非営利**の実演として鳴らす場合は著作権法38条1項の範囲に入りうるが、
**web フォルダごと配布したりネットに公開したりするのは複製・公衆送信にあたる**ため避けること。
配布用のビルドはパブリックドメインの4曲だけにしておくのが安全。

### 自分の UST をその場で歌わせる（ライブモード）

`USTを読み込めるモードで開く.bat`（＝ `python engine/serve.py`）で起動すると、
http://localhost:8000 でデモが開き、ページ上の **「📄 USTファイルを読み込む」** から
任意の UST を選んでその場で合成できる（数秒）。合成結果は曲リストに追加され、
既存の曲と同じように聴きくらべできる。

- UTAU が出力する UST をそのまま渡せる。**Shift_JIS / UTF-8 自動判別**
- 対応済み：連続音（VCV）歌詞 `- か` `a え`、途中のテンポ変更、休符 `R`、
  長音 `ー`（直前の母音を伸ばす）、促音 `っ`、拗音 `きょ` など
- 無視するもの：`PBS/PBW/PBY`（ピッチ曲線）、`Envelope`、`Intensity`、`Flags`、
  原音設定。**音の高さはノート番号から作り直す**（ビブラート・ポルタメントは自動付与）
- 生成物は `web/cache/` に貯まる。消してよい

`デモを開く.bat`（ファイルを直接開く方式）では事前レンダ済みの曲だけが鳴り、
読み込みボタンは無効になる。Python なしで持ち運べるのはこちら。

### コマンドラインから

```bash
python engine/synth.py --ust "C:\path	o\自作.ust"        # 学習モデル
python engine/rule_synth.py --ust "C:\path	o\自作.ust"   # ルールベース
```

### 配布

`web` フォルダ（約12MB）をコピーすれば動く。ただし **PJS の実音声を含む**ため、
配布時は CC BY-SA 4.0 の表示と継承が必要（フッターにクレジットを常時表示済み）。

## 高音域の明瞭度について（対策済み）

学習データ（PJS）の音域は **MIDI 48〜65（F0 134〜349Hz）が中心**で、中央値は MIDI 56。
これを大きく超える音高ではモデルが外挿となり、母音の区別が失われる。

| 音高 | 母音どうしの区別（メルケプストラム距離、大きいほど明瞭） |
|---|---|
| MIDI 55 (196Hz) | 48.5 |
| MIDI 65 (349Hz) | 33.9 |
| MIDI 72 (523Hz) | 17.1 |
| MIDI 79 (784Hz) | 10.7 ← ほぼ崩壊 |

対策：**モデルに渡す音高だけを MIDI 67 で頭打ち**にする（`synth.COND_MAX_MIDI`）。
実際に鳴らす音高は楽譜どおりなので、音程はそのままで音色の明瞭度だけが戻る。
高音でも区別が 29.8 に保たれるようになった（上表の 10.7 → 29.8）。

```bash
python engine/synth.py --ust x.ust --cond_max_midi 0    # 頭打ちなし（比較用）
python engine/synth.py --ust x.ust --cond_max_midi 64   # さらに強く効かせる
```

ただし**物理的な限界は残る**：F0 が 784Hz なら倍音の間隔も 784Hz で、
第1フォルマント（300〜850Hz）の中に倍音が1本しか入らない。
どんな手法でも高音の歌詞が聞き取りにくくなるのはこのためで、実際のソプラノ歌手でも同じ。

### 自動移調（既定でオン）

`synth.auto_transpose()` が、曲ごとに **学習音域（MIDI 48〜67）からのはみ出し時間が
最短になる移調量**を半音単位で探索して適用する。移調しても歌詞と長さは変わらない。

| 曲 | 移調 | 音域 | 音域外の時間 |
|---|---|---|---|
| メルト | **-12**（1オクターブ＝調はそのまま） | 57-81 → 45-69 | 45% → **6%** |
| きらきら星 | -2 | 60-69 → 58-67 | 9% → 0% |
| 音階とあいうえお | -5 | 60-72 → 55-67 | 74% → **0%** |
| かえるのうた／ちょうちょ | 0 | 変更なし | 0% |

```bash
python engine/render_all.py --transpose 0     # 移調しない（比較用）
python engine/render_all.py --transpose -7    # 全曲を7半音下げる
python engine/synth.py --ust x.ust --transpose -12
```

読み込んだ UST（ライブモード）にも自動で適用され、曲名の横に「自動で -12 半音移調」と表示される。

## 残っている作業

1. 生成音を聴いての品質調整（子音長 `CONSONANT_SEC`、ビブラート深さ、ポルタメント時間）
2. 音符ごとの音量制御（いまは一定）
