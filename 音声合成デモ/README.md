# 声のつくりかた（高校生向け 音声合成デモ）

`D:\蝉音声デモ_高校生向け\`（蝉ミキサー）・`D:\手書き文字デモ_高校生向け\`（文字ミキサー）とは
**完全に独立**した別プロジェクト。共有ファイルはなし。

## 使い方（当日）

`デモを開く.bat` をダブルクリック → ブラウザが開く。**Python・GPU・ネット・録音データ すべて不要**。

- **① 母音をつくる**：「あいうえお」ボタン／F0・F1・F2・F3 スライダー／リアルタイムのスペクトログラム。
  スペースキーで発声のオン・オフ。ビブラートと息成分のトグルあり
- **② 母音の地図**：F1–F2 平面。5母音の代表値が五角形に並び、★をドラッグすると
  その場所の声がそのまま鳴る（母音の中間＝日本語にない母音も出せる）
- **③ しくみ**：ソース・フィルタ理論の説明

## 中身の技術

Web Audio API のみで完結する**フォルマント合成**。

| 部品 | 実装 |
|---|---|
| 声帯（ソース） | `PeriodicWave`：倍音を 1/n で並べたパルス列 |
| のど・口（フィルタ） | `BiquadFilter` bandpass ×3（F1/F2/F3、帯域幅 80/90/130 Hz） |
| 息成分 | ホワイトノイズを同じフィルタに通す（既定オフ） |
| ビブラート | 5.5 Hz の LFO で F0 を ±3% 揺らす |
| 表示 | `AnalyserNode` → キャンバスを2pxずつ左送りするスクロール型スペクトログラム |

**録音データは1バイトも入っていません。**すべて計算で生成しているため、
音源のライセンス問題が発生しません。

## 母音の代表値（F1 / F2 / F3 [Hz]）

| | F1 | F2 | F3 |
|---|---|---|---|
| あ | 850 | 1200 | 2800 |
| い | 300 | 2700 | 3300 |
| う | 380 | 1150 | 2600 |
| え | 500 | 2300 | 2900 |
| お | 450 | 800 | 2700 |

成人女性寄りの値。男声にしたい場合は全体を 0.85 倍程度にし、F0 を 110 Hz あたりに下げる。

## 説明の勘所

1. **F0 スライダーを動かしても母音は変わらない** → 声の高さと声色は独立
2. **F1・F2 だけで「あ→え→い」と聞こえる** → 母音の正体は共鳴周波数
3. **録音を一切使っていない** → 「声は作れる」という事実そのものが結論
