# 技術デモ集

大学のオープンキャンパスで高校生向けに使うために作った、音声合成・機械学習系のインタラクティブデモ4本です。
すべて **ブラウザ単体で完結**するように作り込んであり、`デモを開く.bat` をダブルクリックするだけで
Python・GPU・ネット接続なしに動きます。展示用の見た目の裏側では、VAE/GANの実装や
音声のDSP処理、学習済みモデルのブラウザへの移植を自分で書いています。

各フォルダに詳しい技術解説（設計判断・実測値・再現手順まで書いた README）があります。
ここでは全体の見取り図だけ示します。

## 共通する設計方針

- **配布先にPython/GPU/ネット接続を要求しない**：学習・前処理はPythonで行うが、成果物（学習済み重み・特徴量・音声）は事前計算してJSON/JS/wavに書き出し、ブラウザ側のJavaScriptだけで完結させている
- **ライセンス・著作権への配慮**：学習データのライセンス（CC BY-SA等）の継承とクレジット表記、著作権のある楽曲データを公開版には含めないなど、配布可否をそのつど検討している
- **検証を残す**：Python実装とJS実装の数値一致確認（手書き文字デモ）、UIロジックの自動テスト（歌声合成デモの `test_player.js`）など、動けばよしにしていない

## 使用技術（キーワード）

Python / JavaScript（Web Audio API, Canvas）/ PyTorch / VAE, GAN / WORLD vocoder / DSP（STFT, ISTFT, メルケプストラム, フォルマント）/ PCA, k-NN

各フォルダの `デモを開く.bat` をダブルクリックしてください。学習のやり直し方や実装の詳細は各フォルダの README に記載しています。
